## Naming Convention

- **FF7Re** = Final Fantasy VII Rebirth (UE4.26 Square Enix fork)
- **FF7R** = Final Fantasy VII Remake Intergrade (UE4.18 Square Enix fork)
- **Geri** = The Artisan of Glimmith (UE4.27, executable `Geri-Win64-Shipping.exe` — log folder uses this name)
- **Blink** = Extinction (UE4.15, executable `Extinction.exe`, parent dir `Blink/Binaries/Win64/`)
- **SBDR** = MOBILE SUIT GUNDAM SEED Battle Destiny Remastered (UE4.27, Steam; executable `SEED BATTLE DESTINY REMASTERED.exe`, project dir `Game_SBDR/Binaries/Win64/`; internal UClasses use a `Life` prefix — `LifeGameInstance`, `BP_LifeSaveData_C`, etc.)
- **Elliot** = The Adventures of Elliot: The Millennium Tales Demo / 冒險家艾略特的千年奇譚 Demo (UE4.27, SQUARE ENIX, Steam; executable `Elliot-Win64-Shipping.exe`, Steam folder `The Adventures of Elliot_The Millennium Tales Prologue Demo/Elliot/Binaries/Win64/`). The title that motivated the **`dxgi.dll` proxy** (3rd proxy type) — its EXE imports neither `version.dll` nor `dinput8.dll`, only `dxgi`/`winmm`.
- **Avowed** = Avowed (UE5.3, Obsidian, Steam; executable `Avowed-Win64-Shipping.exe`, project dir `Alabama/Binaries/Win64/`). The title that proved **packed 20-byte `FUObjectItem`** support and the **static-struct GObjects AOBs** (`GOBJ_AV1`/`GOBJ_AV2`) for games where no standard/patternsleuth pattern matches. Injects via `dxgi.dll` proxy.
